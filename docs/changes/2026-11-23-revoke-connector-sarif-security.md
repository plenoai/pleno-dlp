Close three security defects from epic #817. Revokes now carry a tri-state `RevokeResult.Outcome` (`confirmed`|`accepted`|`failed`); Hugging Face HTTP 202 maps to `accepted` with `Revoked=false`, the audit trail records `outcome`, `pkg/dlp.RevokeResult` gains `outcome` (APIVersion 1.1.0), and `pleno-dlp revoke` exits 3 for accepted-only revocations (#859). Every credentialed connector client (GitLab, Gitea, Bitbucket, Slack, Notion, Hugging Face, Confluence, OneDev, Pagure) resolves URLs through the shared `apiURL` helper, which refuses absolute links to a foreign origin; Slack file downloads are limited to the API origin or `https://*.slack.com`; Postman per-workspace/collection/environment failures surface as `engine.DegradedError` coverage gaps instead of zero findings (#865). `pleno-dlp view` masks secrets in imported SARIF `message.text` via offline `engine.ScanBytes` (#846).
