Streamed chunks (`Chunk.Open`, filesystem inputs over 512 KiB) now map decoded-variant findings back to the encoded source bytes the way buffered chunks do (#964): the stream batch replays the decoder once per flush via `decoder.StreamSourceSpans` (segment boundaries only, no spooled offset table) and resolves line, `RawSpan`, and inline pragmas (within 64 KiB of the secret) against the raw reader, so allowlist path/line and baseline fingerprints match the in-memory path. Buffered decoded variants longer than one scan window also carry their window offset (`decoder.Variant.Offset`), fixing #982's mapping for findings past the first window. `TestReaderDetectorStreamMatchesInMemoryRawDecodedMetadataAndDedup` now asserts full parity; a 103 MB scan shows no throughput or RSS change versus main. Closes #977.
