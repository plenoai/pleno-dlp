Owners: detector-engineer, core-engineer, qa

Drop unverified findings whose secret is a source-code token: import or file paths made of words, dotted selectors, `SCREAMING_SNAKE` names, and digit-free camelCase/kebab identifiers. The engine applies `detectors.LooksLikeCodeToken` to registered built-in detectors only; password-class detectors (`detectors.AcceptsWordSecrets`), custom rules, and verified results are exempt. JSONConfigSecret now requires a JSON member terminator after the value, so Go map literals such as `"secret": "a" + b` no longer match (#919). It also skips PascalCase type-name keys that hold prose. HardcodedPassword skips `struct{}{}` and call right-hand sides. Doc-comment examples carry inline `pleno-dlp:allow`, and `.pleno-allow.json` now lists only generated catalogs and real fixtures (#943). Engine tests pin URI findings to the URI line when the same short password occurs earlier, including inside a go.sum hash (#920).
