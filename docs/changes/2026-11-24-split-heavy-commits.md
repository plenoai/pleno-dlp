Native git history shards now use a cost-based work plan for histories of at most 20,000 commits: one `git log --raw` pass counts each commit's changed paths, commits are packed into one item per worker by cost, and a commit costlier than one item (croc's vendor imports) is split by path into items rendered with `--literal-pathspecs` and paths on stdin. Trufflehog mode and paths that cannot travel on stdin keep whole commits, and a failed cost pass falls back to contiguous batches. All shard processes start in one burst before scanning and each worker keeps one cat-file batch, because Go forks on darwin and every mid-scan fork made the scanner re-fault its write-protected heap. croc git history drops from 0.54 s to 0.35 s with identical finding sets on croc, rails and django (closes #985, part of #978).
