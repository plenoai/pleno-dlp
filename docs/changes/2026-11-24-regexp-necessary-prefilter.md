Owners: detector-engineer, core-engineer, qa

Guard every detector and format regexp with an exact necessary-condition prefilter derived from its syntax tree (`detectors.Regexp`, `detectors.MustCompile`): required literal sets (ASCII case-folded where the pattern folds) and minimum runs of a byte class (for example 32 hex digits for `\b([a-f0-9]{32})\b`) must be present before the regexp runs; non-ASCII inputs bypass the prefilter. All detector packages now compile through the wrapper, and `TestPrefilterNecessaryForAllPatterns` generates matching strings for every constant pattern and catalog format to prove the prefilter never rejects a match. `generic` lowers windows into a pooled ASCII buffer instead of two window-sized string copies. `scan git` finding sets are identical on croc, django, and rails (#984, #995).
