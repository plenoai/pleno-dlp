Cut git-history scan CPU below kingfisher on croc, django, and rails (#1046, #817). The in-process xdiff finds the common head and tail records by comparing bytes, classifies only the changed middle (head/tail records still count toward middle class totals and are compared by bytes during compaction), and skips classification entirely for added or deleted files; `TestXDiffPrepareMatchesFullClassify` pins the output against the previous full classification. The renderer records hunk line ends so `nativeLineFeed.writeLines` hands lines to the parser without re-splitting them. Format matching reads a lock-free registration snapshot, builds its seen-set lazily, memoizes keyword searches per window, and skips ASCII-keyword formats for dispatch spans that merged no format-keyword hit (every keyword occurrence is an Aho-Corasick hit merged into its span; variants containing U+0130/U+212A keep searching). Case-folded literal search steps between occurrences of the literal's rarest byte, and the Plivo auth-ID scan searches the fixed `A`. The CLI sets a 256 MiB heap-goal floor (`pkg/engine/gcfloor`; goal = max(256 MiB, the GOGC=100 goal), disabled when GOGC or GOMEMLIMIT is set), removing the ramp-up collections that cost about 5% of a small repository's CPU without changing large-scan peak RSS. Findings are identical to main in git and filesystem mode on all three repositories.
