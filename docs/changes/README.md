# Change history fragments

Each change adds one new file here instead of editing a shared table, so
parallel pull requests never touch the same lines.

- File name: `YYYY-MM-DD-<short-slug>.md` (e.g. `2026-11-23-alert-webhooks.md`).
- Body: one line `Owners: <roles>` followed by one paragraph describing the
  change and the issue it closes.

Entries before 2026-11-24 remain in the frozen table in `CLAUDE.md`.
